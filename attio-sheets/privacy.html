Privacy Policy — Attio for Sheets

Effective date: 2026-07-17
Last updated: 2026-07-28
Service: Attio for Sheets (Google Workspace Add-on)
Publisher: Four Ducks / fourducks.dev

What we collect

Attio for Sheets stores the minimum data needed to operate:

  • Your Attio OAuth token — issued by Attio when you click "Connect Attio." Used to call the Attio API on your behalf to fetch People and Companies records.
  • Last-import preferences — which object type (People or Companies) you imported most recently, so the sidebar can pre-set the Refresh button for you.
  • Auto-refresh setting — whether you have enabled the daily trigger.

Nothing else is collected. We do not collect your name, email address, IP address, or any data from your Attio workspace beyond what is written into the spreadsheet you explicitly import into.

Where it is stored

All data is stored exclusively on Google's servers within your own Google account, using Google's Apps Script storage APIs:

  • The OAuth token is stored in User Properties (per-user, private to your Google account).
  • Import preferences and the auto-refresh flag are stored in Document Properties (tied to the specific spreadsheet you are using).
  • Script Properties are used only during the OAuth flow (temporary state token); they are cleared after the callback completes.

We operate no external database, server, or third-party storage. Your Attio token never leaves Google's infrastructure.

How we use it

The OAuth token is used solely to make read-only API calls to Attio (POST /v2/objects/people/records/query and /v2/objects/companies/records/query) to retrieve the records you request. We do not write to your Attio workspace, and we request only the minimum Attio scopes needed: Records → Read and Object Configuration → Read.

Data sharing

We do not sell, share, rent, or disclose your data to any third party, except as required by law. The only external service your token is transmitted to is Attio's own API at api.attio.com, under your instruction when you click Import or Refresh.

How we protect sensitive data

Your Attio OAuth token is the only sensitive data this add-on handles. It is protected by the following mechanisms:

  • Encryption in transit. All network calls are made over HTTPS/TLS. The add-on calls api.attio.com exclusively via UrlFetchApp over TLS; plaintext HTTP is never used, and the token is never placed in a URL query string.
  • Encryption at rest. The token is stored in Apps Script User Properties, which Google encrypts at rest on Google-managed infrastructure. We operate no database, server, or third-party storage of our own, so the token exists in no other location.
  • Access control and isolation. User Properties are scoped to the individual Google account that authorized the add-on. No other user of the add-on, and no employee or contractor of Four Ducks, can read your token — we have no administrative interface, export path, or backend that can access it. Document Properties are similarly scoped to the single spreadsheet they belong to.
  • No logging of secrets. The token is never written to logs, error reports, or Cloud Logging / Stackdriver exception traces. Failed API calls record the HTTP status code and message only, never credentials or record contents.
  • Least privilege. The token is requested with the narrowest Attio scopes that support the feature set (Records → Read, Object Configuration → Read), so it cannot be used to modify or delete anything in your Attio workspace even if it were exposed.
  • No transfer to third parties. The token is transmitted only to Attio's own API, the service that issued it. It is sent to no analytics, monitoring, or advertising provider, and it never leaves Google and Attio infrastructure.
  • Revocation. You can destroy the stored token at any time with the Disconnect button in the sidebar, and you can independently revoke the add-on's access from your Attio account settings.

Because we hold no contact details for users, we cannot notify you directly by email. If we ever become aware of a breach affecting user credentials, we will publish a notice on this page and on the add-on's listing, advise users to disconnect and re-authorize, and inform the relevant supervisory authority where required, without undue delay.

Data retention and deletion

To delete all stored data, click Disconnect in the sidebar. This immediately deletes your Attio OAuth token from User Properties. Document Properties (import preferences) are cleared when you uninstall the add-on via Google Workspace settings. No data is retained on our end because we hold none.

Children's privacy

This add-on is not directed at children under 13. We do not knowingly collect data from children.

Changes to this policy

We will update this page if we change how data is handled. Material changes will be noted with an updated effective date.
